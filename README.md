# Messy Express TypeScript Project

This is an intentionally messy Express.js project with Sequelize ORM, created for **code quality demonstration purposes**.

## Project Structure

```
src/
├── routes/
├── controllers/
├── services/
├── models/
├── middlewares/
├── utils/
├── types/
├── repositories/
└── config/
```

## Installation

```bash
npm install
```

## Configuration

Copy `.env.example` to `.env` and configure your database:

```bash
cp .env.example .env
```

## Running the Project

Development mode:

```bash
npm run dev
```

Build:

```bash
npm run build
```

Production:

```bash
npm start
```

## Purpose

This project is designed to trigger various code quality tools and demonstrate the importance of:

- Code maintainability
- Complexity reduction
- DRY principle
- Security best practices
- TypeScript proper usage
